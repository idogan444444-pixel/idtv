# I&D TV

Private Web-App für eigene Sender-Links, Favoriten, YouTube und M3U-Senderlisten – gedacht für den Browser im Auto (im Stand), auf dem Handy und am PC.

- Alle Daten bleiben im jeweiligen Browser (localStorage). Kein Konto, kein Server, keine Werbung.
- Enthält keine Sender oder Streams. Bitte nur legale Quellen nutzen.
- Videostreams (.m3u8) über [hls.js](https://github.com/video-dev/hls.js) (Apache-2.0, siehe `vendor/hls.LICENSE`).
